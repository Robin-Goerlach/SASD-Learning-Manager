# Privacy and Data Flow

## Lokale Daten

Goals, Skills, Assessments, Paths, Resources, Knowledge, Evidence und History liegen in SQLite. Logs/Backups/Settings liegen lokal im Benutzerprofil.

## Netzwerk

### Link öffnen
`User → Learning Manager → Standardbrowser → Provider`

### Metadata V1.x
`URL → HttpClient → Zielwebsite → begrenzte Metadaten → lokale Resource`

## Kein Netz für

Skill Assessment, Knowledge, Evidence, Dashboard, lokale Search und Backup.
