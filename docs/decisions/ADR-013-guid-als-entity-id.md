# ADR-013: GUID als Entity-ID

**Status:** Proposed  
**Datum:** 2026-08-27

## Context

IDs sollen export/import-stabil sein.

## Considered Options

- INTEGER
- GUID

## Decision

**GUID**

Begründung: portable stabile Referenzen.

## Consequences

größere Schlüssel irrelevant.

## Validation

Vor der ersten davon abhängigen Implementierung wird diese ADR auf `Accepted` gesetzt oder durch eine neue Entscheidung ersetzt.
