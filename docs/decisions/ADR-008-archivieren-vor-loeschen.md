# ADR-008: Archivieren vor Löschen

**Status:** Proposed  
**Datum:** 2026-08-27

## Context

Lernhistorie ist langfristig wertvoll.

## Considered Options

- Hard Delete
- Soft Archive

## Decision

**Soft Archive**

Begründung: Historie bleibt erhalten.

## Consequences

DB wächst moderat.

## Validation

Vor der ersten davon abhängigen Implementierung wird diese ADR auf `Accepted` gesetzt oder durch eine neue Entscheidung ersetzt.
