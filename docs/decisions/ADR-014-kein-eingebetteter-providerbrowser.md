# ADR-014: Kein eingebetteter Providerbrowser

**Status:** Proposed  
**Datum:** 2026-08-27

## Context

Provider-Websites sind komplex und untrusted.

## Considered Options

- WebView2
- Standardbrowser

## Decision

**Standardbrowser**

Begründung: kleinere Angriffsfläche.

## Consequences

weniger integrierte UX.

## Validation

Vor der ersten davon abhängigen Implementierung wird diese ADR auf `Accepted` gesetzt oder durch eine neue Entscheidung ersetzt.
