# ADR-005: Canonical Resource

**Status:** Proposed  
**Datum:** 2026-08-27

## Context

Eine Resource wird in vielen Kontexten genutzt.

## Considered Options

- Kopie pro Path
- Canonical + Relations

## Decision

**Canonical Resource**

Begründung: verhindert Dubletten und widersprüchliche Metadaten.

## Consequences

mehr Join-Relationen.

## Validation

Vor der ersten davon abhängigen Implementierung wird diese ADR auf `Accepted` gesetzt oder durch eine neue Entscheidung ersetzt.
