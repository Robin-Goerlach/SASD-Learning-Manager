# ADR-009: Keine AI-Abhängigkeit im V1-Core

**Status:** Proposed  
**Datum:** 2026-08-27

## Context

AI ist optionaler Komfort.

## Considered Options

- AI-first
- AI optional

## Decision

**AI optional**

Begründung: Offline/Privacy/Determinismus.

## Consequences

Komfort später.

## Validation

Vor der ersten davon abhängigen Implementierung wird diese ADR auf `Accepted` gesetzt oder durch eine neue Entscheidung ersetzt.
