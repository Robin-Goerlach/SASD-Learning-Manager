# ADR-001: WinForms als V1-Oberfläche

**Status:** Proposed  
**Datum:** 2026-08-27

## Context

Die erste Version ist eine lokale Windows-Desktop-Anwendung.

## Considered Options

- WinForms
- WPF
- Avalonia
- Web UI

## Decision

**WinForms**

Begründung: reife .NET-Desktop-Plattform, schnelle Umsetzung und geringe Deployment-Komplexität.

## Consequences

komplexe Graph-UI später separat.

## Validation

Vor der ersten davon abhängigen Implementierung wird diese ADR auf `Accepted` gesetzt oder durch eine neue Entscheidung ersetzt.
