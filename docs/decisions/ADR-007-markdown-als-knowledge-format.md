# ADR-007: Markdown als Knowledge-Format

**Status:** Proposed  
**Datum:** 2026-08-27

## Context

Knowledge soll offen bleiben.

## Considered Options

- Rich Text
- HTML
- Markdown

## Decision

**Markdown**

Begründung: portabel und menschenlesbar.

## Consequences

weniger WYSIWYG-Komfort V1.

## Validation

Vor der ersten davon abhängigen Implementierung wird diese ADR auf `Accepted` gesetzt oder durch eine neue Entscheidung ersetzt.
